## ✨ Key Features
| Feature | Description |
| :--- | :--- |
| **🌐 Automated Scraping** | Continuously monitors LinkedIn, Indeed, and Glassdoor for new postings. |
| **🧠 Resume Matching** | Uses LLMs to score job descriptions against your skills and experience. |
| **📝 Cover Letter Gen** | Automatically generates personalized cover letters tailored to each job. |
| **📊 Application Tracker** | Built-in dashboard to track applications, interviews, and responses. |
| **🔔 Instant Alerts** | Sends notifications via Email or Telegram when a high-match job is found. |

## 🚀 Quick Start
Get AI Job Scout up and running to automate your job search.

```bash
# Clone the repository
git clone https://github.com/suprit-4618/AI-Job-Scout.git

# Navigate to project
cd AI-Job-Scout

# Install dependencies
pip install -r requirements.txt

# Configure your profile and API keys
cp config.example.json config.json
# Edit config.json with your details

# Run the scout
python scout.py
```
