### "Find the exact answer, not just keywords."
This Agentic RAG (Retrieval-Augmented Generation) Engine leverages the power of vector databases and local LLMs to provide deep, contextual search capabilities. It goes beyond simple keyword matching by using intelligent query decomposition and multi-step reasoning.

## ✨ Key Features
| Feature | Description |
| :--- | :--- |
| **🔍 Vector Search** | High-performance semantic retrieval using Sentence-Transformers and Qdrant/Pinecone. |
| **🤖 Agentic Workflow** | Intelligent query decomposition and multi-step reasoning for deep data analysis. |
| **🔒 Local LLM** | Privacy-focused execution using Ollama (Llama-3/Mistral) for offline search capabilities. |
| **⚡ Fast Indexing** | Optimized document chunking and embedding pipelines. |
| **📊 Insight Generation** | Synthesizes multiple data points into comprehensive answers. |

## 🚀 Quick Start
Get the Agentic RAG Engine up and running on your local machine.

```bash
# Clone the repository
git clone https://github.com/suprit-4618/Semantic-Search.git

# Navigate to project
cd Semantic-Search

# Install dependencies
pip install -r requirements.txt

# Ensure Ollama is running locally with Llama-3/Mistral
# ollama run llama3

# Run the search engine
python main.py
```
