## ✨ Key Features
| Feature | Description |
| :--- | :--- |
| **🎙️ Voice Activated** | Real-time wake-word detection using Picovoice Porcupine. |
| **🧠 LLM Brain** | Powered by Groq and Google Gemini for ultra-fast reasoning. |
| **📺 Glassmorphism HUD** | Futuristic UI built with Electron and React for a premium experience. |
| **🛠️ OS Integration** | Execute WhatsApp messages, app automation, and terminal control. |
| **⚡ Ultra Low Latency** | Optimized for instant responses and smooth animations. |

## 🚀 Quick Start
Get FRIDAY up and running on your machine in under 2 minutes.

```bash
# Clone the repository
git clone https://github.com/suprit-4618/FRIDAY.git

# Navigate to project
cd FRIDAY

# Install dependencies
npm install

# Set up environment variables (.env)
# API_KEY=your_gemini_or_groq_key

# Run the app
npm start
```
